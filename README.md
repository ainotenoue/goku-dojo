# 語句道場

中学受験・国語の語句問題を4択で練習するWebゲーム（iPad向け）。

## 分野
- ことわざ・慣用句（□に漢字一字）
- 敬語
- 多義語
- 外来語
- 文学作品と作者

## 機能
- 1回の問題数は5・10・20問から選択
- まちがえた語句は「復習ノート」に残り、2回続けて正解すると消える
- 未出題・苦手な語句を多めに出題
- 進み具合はブラウザの localStorage に保存（端末ごと）

## 公開
GitHub Pages（`main` ブランチ / root）で公開。

## 問題の追加
`index.html` 内の `K`（ことわざ・慣用句）、`G`（敬語）、`T`（多義語）、`W`（外来語）、`B`（文学作品）の配列に行を足す。

## 注意
過去問のPDF・画像はこのリポジトリに入れない（学校の著作物のため）。問題はすべて自作。
